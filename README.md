# Сайт Aikoz — готовая папка для GitHub Pages

Это продающий сайт Aikoz в виде обычных файлов: HTML, CSS и JavaScript. Ему не нужны сборка, Node.js и
установка программ — папку можно выложить на любой хостинг как есть.

Сайт сделан из `demo_site/` (React-версия). Здесь только публичная часть: без связи с очками, без режима
показа и без раздела «Путь Aikoz».

## Как посмотреть у себя на компьютере

Двойной щелчок по `index.html` **не сработает**: браузер не загрузит скрипты и 3D с диска. Сайт нужно
открыть через маленький локальный сервер. Любой из двух способов:

**Способ 1 — Python.** Откройте PowerShell в этой папке и выполните:

```powershell
& "$env:USERPROFILE\develop\glasses-venv\Scripts\python.exe" -m http.server 8080
```

Затем откройте в браузере адрес `http://localhost:8080`. Остановить сервер — `Ctrl + C` в окне PowerShell.

**Способ 2 — VS Code.** Установите расширение «Live Server», щёлкните правой кнопкой по `index.html` →
«Open with Live Server».

## Как выложить на GitHub Pages

1. Создайте на GitHub **публичный** репозиторий (например `aikoz-site`).
2. Скопируйте в него **содержимое** этой папки — так, чтобы `index.html` лежал в корне репозитория,
   а не внутри `pages_site/`. Файл `.nojekyll` тоже нужен (он пустой, но без него GitHub может
   пропустить часть файлов).
3. В репозитории откройте **Settings → Pages**. В «Build and deployment» выберите
   **Deploy from a branch**, ветка **main**, папка **/ (root)**, нажмите **Save**.
4. Через одну-две минуты сайт откроется по адресу `https://<ваше-имя>.github.io/<имя-репозитория>/`.

Все пути на сайте относительные, поэтому он работает и по такому адресу, и на своём домене.

Когда появится постоянный адрес, впишите его в `index.html` в строках `og:image` (полный адрес картинки
`og-image.png`) — тогда ссылка в мессенджерах будет с картинкой.

## Где что менять

| Что | Где |
|---|---|
| Тексты разделов (первый экран, функции, коробка, цена, подписка, вопросы) | `index.html` — текст написан прямо в разметке |
| Тексты, которые подставляют скрипты (распаковка, 3D-осмотр, пробы, инструкция, форма вопроса, сообщение в WhatsApp) | `js/content/ru.js` |
| Телефон, WhatsApp, почта, Instagram, Telegram | `js/content/contacts.js` — пустое поле на сайте не показывается |
| Цвета, шрифты, вид кнопок и панелей | `css/base.css` — цвета записаны один раз, в начале файла |
| Расположение и размеры блоков страницы | `css/page.css` |
| Снимки экранов приложения | папка `app/` (имена файлов — в `index.html`, раздел «Приложение») |
| Картинки распаковки без 3D | папка `img/` (список имён — в `js/sections/story-static.js`) |

Некоторые тексты есть в двух местах — в `index.html` и в `js/content/ru.js` (например, названия разделов
меню и вопросы). Сайт показывает то, что написано в `index.html`; если меняете такой текст, поправьте
оба файла, чтобы они не расходились.

Правила, которые важно не нарушить:

- В `index.html` нельзя писать `style="…"`, блоки `<style>` и код внутри `<script>` — страница защищена
  (строка `Content-Security-Policy` в начале файла), браузер их просто не выполнит. Стили — только в
  файлах `css/`, код — только в файлах `js/`.
- Без выдуманных цифр, отзывов и партнёров; цена — «скоро»; название — «Aikoz» латиницей.

```
index.html                страница: шапка, разделы, подвал
css/fonts.css             подключение шрифтов

                          explore.js (3D-осмотр)

js/moon/                  луна, звёзды, космос за страницей

js/ui/, js/lib/           общие помощники: сборка разметки, движение, окна
js/scene/, js/explore/, js/trials/   3D и пробы
vendor/                   библиотека three.js (3D)

```

## Если что-то не работает

- **Пустая страница без 3D и без звёзд** — сайт открыт двойным щелчком. Откройте через локальный сервер (см. выше).
- **Нет 3D, вместо распаковки картинки с кнопками «Назад» / «Дальше»** — так и задумано, если браузер
  не умеет 3D или в системе включена настройка «меньше движения».
- **После правки ничего не изменилось** — обновите страницу с очисткой кэша: `Ctrl + F5`.
